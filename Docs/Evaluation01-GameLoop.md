# 評価課題01 ゲームループと創意工夫

## 検討した案と採用理由

| 案 | 方針・理由 |
| --- | --- |
| 最終クリアからタイトルへ戻る | 採用。実行ファイルを再起動せず何度でも遊べる。 |
| コンボ得点と起動中のベスト得点 | 採用。狙い撃ちと複数球を使った連続破壊に、速さを意識する目標を加える。 |
| 短い破片演出 | 採用。破壊の手応えを強める。衝突なし・短寿命にして盤面を妨げない。 |
| 状態別の操作案内 | 採用。発射待ちや最終クリア後に次の操作が分かる。 |
| 破壊不能ブロック・貫通弾・速度上昇 | 今回は不採用。既存の衝突と難易度を大きく変え、導入ステージの遊びやすさを損ねる可能性がある。 |

## 実装仕様

- タイトル→Level1→Level2→タイトルをSpaceで進む。最終クリアから戻ったときは残球引き継ぎ値を未設定、得点を0にする。ベスト得点はアプリ起動中のみ保持する。
- 通常は100点。4秒以内の連続破壊で倍率を1ずつ上げ、最大x5。4秒経過または落球でコンボを解除する。重複した破壊通知では加点しない。
- ステージ移動では得点を引き継ぐ。ゲームオーバー再開時はステージ開始時の得点へ戻し、同じブロックの繰り返し再挑戦による加点の積み上げを防ぐ。
- 追加HUDは右上、操作案内は画面下。元の残球・クリア・ゲームオーバーWidgetは維持する。
- 破片は既存のCubeとBlockMaterialを使い、6個が放射状に飛びながら縮小する。寿命0.45秒、Collisionなし、Overlapなし。新しい外部素材は使用しない。
- 白いパドルとボール、ステージ配置、ボール速度、アイテム確率を変更しない。

## 検証

`Breakout.Evaluation01.TwoCyclesScoreAndFeedback`を追加。Space入力によるタイトル開始・Level1クリア後遷移・Level2ゲームオーバー再開・最終クリア後タイトル復帰を2周検証する。テスト中のブロック破壊と落球は直接実行して状態遷移を検証するもので、手操作による2周の完走とは区別する。

コンボの期限と上限、重複加点防止、得点引き継ぎと再開時の巻き戻し、HUDが1つだけ生成されること、破片の衝突無効と消滅も検証する。既存の回帰テスト6件も実行する。
