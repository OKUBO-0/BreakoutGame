# BreakoutGame

ND1 評価課題01「ブロック崩し」

クラス：LE4B / 出席番号：06 / 氏名：オオクボ タク

## 起動・操作方法

ZIPをすべて展開し、`BreakoutGame.exe`を起動してください。Windows 64bit用、1280×720のウィンドウ表示です。Unreal Engineのインストールは不要です。実行ファイルだけを別の場所に移動せず、同梱フォルダの構成を維持してください。

初回起動時にVisual C++ランタイムが不足している場合は、同梱の`Engine/Extras/Redist/en-us/vc_redist.x64.exe`を実行してください。

- タイトル画面：Spaceでゲーム開始。
- パドル移動：Aを長押しで左、Dを長押しで右。
- ボール発射：場にボールがないときにSpace。残りボールを1つ消費します。
- ゲームオーバー：Spaceで現在のステージを残りボール3個から再開。
- Level1クリア：SpaceでLevel2へ進みます。
- 終了：ウィンドウ右上の閉じるボタン、またはAlt+F4。

## ゲームのルール

ブロックをすべて破壊するとステージクリアです。ブロックの数字は残り耐久値で、耐久値に応じて色も変わります。パドルに当たる位置によってボールの反射方向が変わるため、左右の端を使って狙いを調整できます。

ブロック破壊時には50%の確率で「A」のアイテムが落下します。パドルで受け取ると、残りボールを消費せず新しいボールが追加されます。複数のボールが場にある間は、1個落としてもプレイを続けられます。残りボールと場のボールが両方0になるとゲームオーバーです。

Level1からLevel2へは、クリア時の「残りボール＋場にあったボールの数」を引き継ぎます。BGM、衝突SE、クリア・ゲームオーバー表示のアニメーションを実装しています。

## アレンジした箇所

- Level1はHP1の5ブロックを1段に配置し、操作と反射を覚えやすい導入ステージにしました。
- Level2は10ブロックを4段の三角形に配置し、耐久値の異なるブロックを狙って崩すステージにしました。
- パドルとボールを白く統一し、外枠の角は追加キューブを使わず壁の長さで隙間を埋めました。
- BGMと衝突SEは、この作品用に生成したオリジナル音源です。

## 最終ステージについて

Level2が最終ステージです。クリア後は結果画面に留まり、Spaceでは遷移しません。最初から遊び直す場合は、ゲームを終了して起動し直してください。

## 開発用リポジトリについて

UE 5.8.3で制作しています。ゲーム処理はC++とBlueprintアセットを組み合わせています。配布ZIPには、ソースコード・開発用MCP・検証ログ・GIF・キャッシュを含めません。

開発用のパッケージ生成は`Tools/Package-Windows.ps1`、提出用ZIPの生成は`Tools/Prepare-Submission.ps1`を使用します。
